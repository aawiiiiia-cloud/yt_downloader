  解析与下载统一采用公开播放器链接。选定 HLS 视频画质时，优先匹配同 CDN 的音频；该线路无音频格式时才使用其他可用音频。

  优先读取左侧网页已经取得的该视频数据，包括页面初始数据、JSON 序列化的 React 页面数据及正常播放器接口响应。
  等候迟到数据约 7 秒，仍缺失时回退 yt-dlp 常规解析，并给出加载、验证或登录后重试的提示。
- 抖音浏览器格式保留逐画质分辨率、编码、帧率和源文件大小；仅接入完整 MP4 条目，排除尚未配对音频的 DASH 条目。
  媒体和封面地址仅允许已适配的站点素材域名，当前视频编号不匹配的数据不能入队。

复现自动检查：

```powershell
& 'D:\python-envs\yt-downloader\Scripts\python.exe' -B -m unittest test_collector_new_sites test_yt_dlp_gui test_xhs_image_downloader test_media_batch test_collector_core
npm.cmd run check
npm.cmd test
npm.cmd run test:electron
```

`test:live` 默认只浏览、解析元数据；下载需要显式设置 `YT_COLLECTOR_TEST_DOWNLOAD=1`。
自定义目标 JSON 为 `[["vimeo","视频网址"],["douyin","视频网址"]]`，通过 `YT_COLLECTOR_TEST_TARGETS` 指定文件。
`YT_COLLECTOR_TEST_PREVIEW=1` 检查封面；`YT_COLLECTOR_TEST_SITE` 可只运行一站。
下载默认选不超过 360p 的较低画质；必要时通过 `YT_COLLECTOR_TEST_MAX_HEIGHT` 提高上限（144–2160），估算超过 64 MB 时拒绝样本下载。
