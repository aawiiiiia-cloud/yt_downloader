# 淘宝图片采集集成（2026-10-25）

## 完成范围

在 `c2d4b3e` 基础上接入“淘宝”分组，合并淘宝、天猫、天猫超市的商品图片入口。
仅采集商品主图、SKU 图、详情图，不处理电商视频。
本次完成应用集成与隔离测试；真实站点三条样例尚未验收，不能据此宣称所有商品模板已适配。

用户流程：重启应用 → 淘宝分组 → 打开商品详情页 → 必要时登录 → 解析当前页面 → 选择主图 / SKU 图 / 详情图 → 单张下载或多选加入队列。
自动解析继续默认关闭，保留旧结果与手动更新的既定行为。
若详情分类为 0，会提示在左侧展开图文详情后重新解析，不将未加载内容称为完整采集。

## 实现

- `electron/taobao-page.cjs`：独立编写的媒体快照提取，不直接复制调研仓库源码。兼容已加载的商品 JSON 和限定商品区域 DOM，包含懒加载地址、srcset、SKU 图片和背景图。
- 只输出商品图片字段与名称，不输出账号、Cookie、令牌、视频数据，也不扫描全页任意字符串中的 CDN 地址。
- 有商品 ID 的站点数据必须匹配当前商品；检测到旧商品状态时拒绝将其归到新商品。DOM 区域排除推荐和评价图片。
- `taobao_adapter.py`：绑定商品快照，生成主图 / SKU 图 / 详情图；同类图片去重，同一 SKU 图片的多个名称保留。分类之间保留各自用途。
- 仅三个明确的商品主机与 `/item.htm?id=...` 可采集，保留原主机及 skuId；其余网页可正常浏览，但不进入商品解析。
- 原图候选只改写可信阿里图片 CDN 的已知缩放后缀，保留查询参数，失败后回退网页提供地址。预览图尺寸不冒充原图尺寸。
- 预览与源文件大小请求携带来源站点根地址，缓存仍包含商品来源。完整商品路径及查询参数不写入跨域 Referer，避免触发 Chromium 默认来源策略的请求校验。
- 复用原有 Pillow 解码、完整性检查、格式转换与原子保存；仅抽出保存目录方法供淘宝按分类组织，原有小红书与 Behance 路径不变。
- 图片请求使用现有 requests 依赖；每次重定向先校验 CDN、协议、端口与文件路径，禁止跳转到本机或其他素材域名。单张图片上限 100 MB。
- 保存目录：`设置目录 / 商品标题 [商品ID] / 主图、SKU 图、详情图 / 原顺序编号.真实扩展名`。分类内的 `product.json` 记录序号与 SKU 名称，不写入临时图片地址或登录信息。
- 原有单张按钮继续使用；淘宝任务名称附带分类和单张编号。分类切换保留各自勾选，下载绑定已解析快照。
- 登录区提供登录、Edge 登录、Cookies 文件导入；淘宝 / 天猫 Cookie 范围合并，匿名 `_tb_token_` 不计作账号登录。未强制登录或改变原有 YouTube 验证门槛。真实淘宝账号登录链路尚未验证。

## 同日修复：预览与大小请求 ERR_BLOCKED_BY_CLIENT

用户报告主图、SKU、详情图均无法预览，错误为 `net::ERR_BLOCKED_BY_CLIENT`，文件大小和像素尺寸未知。
定位为本应用在跨域图片请求中直接设置完整商品 URL（包含路径和查询参数）作为 Referer，与 Chromium 默认的来源策略校验冲突。
其他站点使用站点根地址，未触发这个新分支的条件。此问题不同于调研工具对商品页浏览的访问策略限制。

本机 Electron 45 的回环 HTTP 图片服务复现：

- 完整跨域 HTTP 来源（`http://source.example/item.htm?id=...`）：返回相同错误，服务端请求数为 0。
- 来源站点根地址（`http://source.example/`）：服务端收到请求并返回 200。
- HTTPS 来源到该 HTTP 测试服务属于降级请求，同样受策略限制；生产素材使用 HTTPS。本次没有修改浏览器安全开关或放宽来源策略。

修复：所有素材请求统一将已验证来源裁剪为 origin，保留默认策略。预览和大小请求共用的入口一起修正。
另外，原先像素尺寸只取页面信息；淘宝页面未提供原图宽高时，新增读取原图文件头补齐 JPEG、PNG、GIF、WebP 宽高。读到尺寸立即取消响应，最多保留 256 KiB 头部；服务端忽略 Range 时也有相同保留上限。无法识别的格式或超出头部范围时仍显示“尺寸未知”，不拿预览图、回退图尺寸代替原图。
文件字节大小继续取 HEAD / Content-Range；即使宽高补查未成功，也保留已读取到的有效文件大小。

新增 `electron/media-network-smoke.cjs`，使用本地服务与真实 Chromium 网络栈，通过生产素材请求入口验证该条件；此前 `protocol.handle` 返回受控响应的测试没有覆盖这一校验，已补足该回归盲点。
本次 84 项 JavaScript 检查、174 项原生窗口检查及独立进程重启恢复通过。Python 未变更。
诊断证据在忽略的 `electron-artifacts/referrer-probe-result.json`；窗口结果在 `electron-artifacts/smoke-result.json`。
