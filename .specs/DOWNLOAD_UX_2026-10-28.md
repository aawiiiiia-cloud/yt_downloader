# 下载交互、速度与跨站进度改进（2026-10-28）

## 用户需求

- 根据录屏让下载图标从按钮附近弹出，飞向“下载任务”。
- 下载任务卡片右上角显示速度。
- 检查其他站点是否存在小红书式 0% / 等待无日志问题。

## 实现

### 任务入队反馈

`electron/ui/download-feedback.js` 提供独立反馈组件；只有下载接口返回任务 ID 后才播放。图标从点击位置轻弹后沿弧线飞向下载任务标签，约 780 毫秒；到达后标签轻微强调。一次批量下载只飞一个图标。单图下载继续停留在资源页；批量/视频保留原来的自动进入下载任务行为，但延后至飞入结束，且不覆盖用户期间的主动切页。

- 提前保存点击位置，避免请求期间资源重绘丢失按钮。
- 失败、不成功入队、重复点击不产生成功动画。
- 不引用外部图片，不放宽安全策略；图标不拦截鼠标操作。
- 减少动态效果时只显示到达提示；窗口调整、页面卸载、动画拒绝均清理临时节点。
- 同时最多三条飞行动画，避免独立任务连续点击积累。

### 下载速度

队列保留速度（字节/秒）、更新时间及 ETA。卡片右上角按 B/s、KB/s、MB/s、GB/s 显示，采用 1024 进位。图片显示本次网络请求从开始接收到当前的平均速度；视频使用下载核心回传的当前速度，不将校验、磁盘写入或合并速度冒充下载速度。

- 真实 0 B/s 和缺失速度分开处理，拒绝 NaN、无限与负值。
- 连接时显示等待连接；未接收数据时显示等待数据；校验、转换、合并时显示该阶段。
- 六秒没有新的速度样本就显示等待数据，避免卡在旧速度。
- 每秒仅刷新速度文本，不因此重建卡片或关闭日志。
- 结束、失败和取消后清除实时速度；历史卡片不显示旧的速度。

### 跨站审查

| 下载路径 | 审查结论与改动 | 验证范围 |
| --- | --- | --- |
| 小红书图片 | 已有字节进度与连接日志；增加真实接收速度 | 真正本机 HTTP 慢流、未知大小、超时、回退、取消 |
| 淘宝/天猫图片 | 之前仅保存完一张后回传进度；接通共享图片连接/接收/校验/转换进度及速度 | 实际适配器 + 模拟 HTTP 响应，检查发布文件前已有进度 |
| 站酷图片 | 同样只在整张结束更新；补齐共享进度及速度，保留签名地址、实际尺寸校验、不降级缩放图 | 实际适配器受控下载 + 原有尺寸/权限回归 |
| Behance 图片 | 同样缺少传输阶段回传；补齐共享进度与速度，保留 GIF、稀疏编号和格式转换 | 实际适配器受控下载 + 原有原图/GIF/安全回归 |
| YouTube、B站、小红书视频、Vimeo、抖音、Behance/Adobe 视频、站酷视频 | 本来均接入下载核心钩子，速度没被队列保存/展示；未知总大小还回传 0%。现在保留速度和已接收字节，未知大小使用不定进度；解析前发布准备日志和阶段，后处理清空速度 | 七站通用下载选项及实际进度钩子、队列、原有视频/外部资源回归 |

Vimeo 的并行线路查询是解析阶段，不是实际下载；原来的有限网络等待、重试和取消策略保留。淘宝当前仅适配商品图片，不声称已支持视频。站点风控、权限、过期下载地址、账号与网络限制仍可能导致下载失败，本次不绕过网站验证。
