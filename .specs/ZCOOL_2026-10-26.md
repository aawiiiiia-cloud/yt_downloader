# 站酷作品图片接入

首期范围：当前单个站酷作品详情页的正文图片。站酷分组具有既有多标签、手动解析、预览、大小查询、单张下载、下载所选、全局/单站并发、取消与重试能力。视频、作者主页、搜索及收藏夹批量暂未接入。

## 解析来源与身份

- Electron 从当前已加载作品的 script#__NEXT_DATA__ 读取 props.pageProps.data.productImages，不请求后台绕过登录或验证。
- 必须匹配当前作品 URL 与 JSON query.id；保留 Base64 风格作品 ID 的大小写及等号，不依赖会变化的内部数字 ID 换算。
- 只传出标题、公开作者、图片 ID、页面提供的地址及尺寸，最多 400 张；账户数据、proofToken、推荐图片、完整页面状态不会进入采集上下文。
- 参考 [MIT 浏览器扩展](https://github.com/dddzzz123-dz/zcool-downloader) 的数据来源；本项目单独实现轻量适配，不安装或执行第三方下载程序，无新增依赖。

## 图片质量与下载

- 仅使用页面实际提供的 urlBig / url 下载候选，按可识别的缩放宽度选较大者；urlSmall 只用于预览。
- 保留 URL 全部查询参数，包括 x-oss-process、k/t 等；不以删参数或改路径推测未授权原图，不降级到预览地址。
- 页面标注宽高保存为 expected_width/expected_height，不把它直接当作当前下载文件的尺寸；资源卡片从响应头部读取真实图片宽高。
- 复用既有请求会话、代理、Cookie、重定向白名单和原子图片保存；站酷下载允许站酷自有素材域名，跨到本机或其他域名的重定向被拒绝。
- 图片完整解码后、转换及最终保存之前比较宽高（考虑 EXIF 旋转）。实际小于标注尺寸时不保存，任务显示 IMAGE_RESOLUTION_LIMITED / 图片清晰度受限。
- 该状态不会被归类为登录凭据过期，不自动停用账号。没有标注尺寸时保存可访问图片，但日志明确尺寸未核验。
- 正常保存保留原顺序编号；work.json 只记录作品信息与实际尺寸，不含临时签名地址和账号凭据。尺寸核对不等于字节级确认作者最初上传的文件。

## 登录与人工验收

站酷提供“登录”和“导入 Cookies”。尚未确认可可靠代表登录完成的 Cookie 名称，不将 JSESSIONID 等匿名 Cookie 当登录证据，账号区显示“登录状态以左侧网页为准”，暂不提供 Edge 自动完成检测。
Cookie 快照仅包含 zcool.com.cn 及其站酷 CDN zcool.cn 相关域。用户在网页中完成登录/必要验证，返回作品页刷新，再手动解析。

用户验收页：[每一位健身的人都想练成一座古希腊雕塑](https://www.zcool.com.cn/work/ZNzQyNjY2ODg=.html)，作者吴春雷。
调研时未登录：正文清单 28 张，28 张均有宽高；第一张标注 2968×3957，浏览器实际预览 1280×1707；28 张 urlBig 均含缩放参数。
这证明图片清单可读取，不能作为原图下载验收。2026-10-26 用户在实际应用登录后反馈第一张下载成功，文件尺寸 2968×3957、大小 2.09 MB，与作品标注尺寸一致。这是用户报告的单张高清验收，尚不代表完整 28 张及顺序均通过，也不等于作者上传文件的字节级一致性证明。
如果登录后的页面仍只提供缩放地址，仍会提示清晰度受限，应继续核对登录后的实际资源入口，不能宣称已取得原图。
