# 站酷原生视频接入

范围：从左侧当前单个作品提取 `productVideos` 中站酷 `video.zcool.cn` 托管的 MP4。
保留正文图片集，视频为单独的资源条目；纯视频作品无需图片。第三方视频与其他视频格式暂时跳过并提示，不自动转到其他平台下载。

## 数据与参数

- 快照绑定当前作品 URL / query.id，最多 400 张图片、24 个原生视频，仅传公开媒体 ID、URL、封面及尺寸字段；proofToken、账号资料、推荐内容与完整页面状态不转发。
- HTTPS、固定媒体主机、端口及凭据检查在 JS / Python 两侧执行；保留网页提供的完整签名和查询参数，不拼接原片或更高清地址。
- 请求在同一视频会话中采用站酷来源、所选代理和本站 Cookie。每次重定向都再次检查媒体主机，不访问本机或其他网站。下载使用 yt-dlp HTTP 下载器，并由相同有界、可取消的请求适配器提供流。
- 元数据请求优先读取 256 KB，通过 MP4 顶层 atom 的长度跳过 mdat，必要时 Range 读取 moov。最多读取 2 MB、16 个顶层 atom，网络有总时间预算；本地 ffprobe 只读抽取到的元数据，禁用外部数据引用和网络协议，进程限时 4 秒。
- 尺寸、音轨、时长来自实际视频元数据；总大小来自 Content-Range / Content-Length。网页播放器标注可能是展示尺寸，不作为实际画质；无法识别时显示未知。临时元数据查询失败仍允许尝试实际下载，明确拒绝访问或加密视频显示不可用。
- 卡片复用封面、时长、大小、画质、MP3 和下载所选控件。只列出页面实际提供的 MP4，不猜测其他清晰度；图片缩放提示只在图片条目出现。

## 下载与任务

- 作品上下文和 mediaId 冻结在私有任务中，下载前再次验证作品与视频 ID。公开格式列表、任务历史不保存视频签名 URL；日志和错误沿用现有脱敏。
- yt-dlp 负责进度、断点续传、重试、临时文件和 MP3 后处理；不改变视频分片并发。HTTP 错误、超时、取消沿用现有任务分类，不把普通 403 推断为账号凭据失效。
- 全局、单站额度沿用设置。不同视频有不同输出文件身份，同一视频的重复输出仍串行，图片集共享清单的串行保护保留。
- 无新增依赖，使用随包 requests、yt-dlp、FFmpeg / FFprobe。

## 验收

用户作品：https://www.zcool.com.cn/work/ZNzQyNDUwOTY=.html ，《AI概念短片-寻橡奇旅》，N30DESIGN。

- 已在隔离的真实 Electron 浏览会话从实际页面解析出 22 张图片和 1 个视频，并显示真实封面；没有登录、导入 Cookie 或操作网站验证。
- 页面标注 720×405，实际视频为 1920×1080，时长 96.04 秒，大小 45,081,788 字节；已按真实参数显示 1080p、01:36、45.08 MB。
- 已通过新下载器完整下载，ffprobe 验证 H.264 视频与 AAC 音轨，FFmpeg 全片解码无错误。SHA-256：`c3febe7e62e92d0fd8b3ed8dcc3a627c55adb37c320ec337d7c420ddc2717d48`。完整媒体只在源码的忽略测试目录中，交付包不携带该视频。
- 自动检查：244 项 Python、118 项 JS；240 项 Electron 隔离界面检查与独立进程重启恢复。新增检查覆盖混合/纯视频作品、签名与隐私、元数据在 mdat 后、读取上限、重定向拒绝、选择身份、真实 yt-dlp 字节保存、MP3、失败、取消、不可用视频保留图片及队列并发。
- GUI 自动化中的账号状态为受控测试状态；真实作品检查和真实下载均使用匿名会话。这只验证本样例，不代表全部站酷视频或受限作品均可访问。
